О системе

Система предназначена для интеллектуального анализа открытых данных мониторинга эффективности деятельности образовательных организаций высшего образования, который ежегодно проводит Минобрнауки России. Источник данных — информационно-аналитические материалы на сайте monitoring.miccedu.ru.

Система решает три задачи:

  1. Прогноз класса результативности организации в следующем мониторинге с помощью нейронной сети: «зона риска» (не ниже медианы по России 0–1 показателя из пяти), «средний уровень» (2–3 показателя), «лидеры» (4–5 показателей).
  2. Поиск нетипичных профилей — организаций, показатели которых плохо согласуются между собой (автокодировщик), и объединение организаций в типологические группы.
  3. Сравнение организации с медианами по России, региону и ведомству, с другими вузами.

Как читать результаты

Класс результативности

Зона риска Средний уровень Лидеры

Определяется числом основных показателей (E.1, E.2, E.3, E.4, E.8), значения которых не ниже медианы по России в соответствующем году.

Вероятности прогноза

Нейронная сеть выдаёт три вероятности, в сумме равные 100 %. Чем ближе наибольшая из них к 100 %, тем увереннее прогноз. Прогноз — основание для анализа, а не окончательный вывод.

Оценка нетипичности

Ошибка, с которой автокодировщик восстанавливает показатели организации. Высокое значение означает редкое сочетание показателей: это повод проверить отчётные данные.
